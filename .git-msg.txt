真凶与修法
1) agent/created 的载荷提取太窄：原来只认 args[0].agent，形状不符时**静默失败**
   （订阅永远挂不上、日志里什么都没有）。改为 pickAgent()：在载荷里浅层找带 ctx 的对象
   （支持 { agent } / agent 本体 / 嵌套包装 / 其它键），并记录载荷键名。
2) agent 在 App 启动之后才创建：装载时 agents.list() 为空（injectAgentCount=0），
   而根上下文的 session/event 收不到任何东西 → 必须有别的入口补挂。
   新增 reconcileAgents()（**无定时器**，设计红线），由 session/created、turn/start 两条生命周期兜底触发。
3) 诊断新增 lifecycleSeen / lifecycleShapes：下一次重启即可判定
   「事件到没到、形状对不对」，不用再猜。
