fix(core+panel): 修「服务访问即抛错」导致 App 起不来（core 0.1.12 / panel 0.0.2）

事故（我造成的，两处同因）
Cordis 对未在 inject 里声明的服务，属性访问在读取那一刻就抛错：
- core: cannot get property "agents" without inject at registerQaLoop → 整个 core 装载失败
- panel: 读 ctx.slots 而 inject 为 []（崩溃日志只给 web boot: 1 entry did not activate @oblivion/panel: failed）
我上一批把这两处裸读写在了 try/catch 之外（core 甚至写在对象字面量里），
结果诊断代码炸掉了 App 启动。

修法
- core: 新增 safeRead()；agentsDirect / agentsDirectCount / 初始 agents 探测全部走它
  （诊断字段退化为默认值，绝不阻断装载）
- panel: 客户端 inject 改为 ['slots']（左栏入口确实需要它），并把 ctx.slots 的读取也放进 try/catch
- 回归自证（临时脚本，跑完即删）：构造「agents/slots/betterSidebar/webServer 读取即抛错」的上下文，
  断言 core.apply 与 panel.apply 都装载成功 → 两条 PASS
