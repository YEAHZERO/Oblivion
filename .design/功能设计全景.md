## 三、核心认知功能（F 类 — 这是 Oblivion 的灵魂）

| # | 功能 | 说明 | 出处 |
|---|---|---|---|
| F1 | **问答闭环** | 捕获问答 → 四层筛选 → 注入知识库 | §2.2 F1、§12.1、§25.1 |
| F2 | **思维激荡（主动触发）** | 单次提问后自动附加 1 个相关新视角 | §2.2 F2、§12.2、§25.4 |
| F3 | **思维激荡（深度触发）** | 连续 ≥3 次追问同维度后生成 ≥3 候选视角 | §2.2 F3、§12.2 |
| F4 | **图谱生长** | 问答共现建边、权重累积、双链写回 MD | §2.2 F4、§25.6 |
| F5 | **反馈画像** | 点赞/点踩/中性信号，累积后微调用户画像 | §2.2 F5、§25.7 |

### F1 问答闭环的四层筛选细节（§25.1）

| 层 | 机制 | 阈值 |
|---|---|---|
| L1 精确去重 | SHA256 哈希比对 | 完全相同 → 丢弃；<10ms |
| L2 语义去重 | `hybrid-search` 相似度 | >0.85 → 判定重复 |
| L3 规则过滤 | 基础规则 | 答案 <5 字 / 无意义词 / "不知道" / 纯寒暄 → 丢弃 |
| L4 价值评估 | **首版纯规则** | 命中低价值规则 → 不注入 + 决策留痕 |

### F2/F3 思维激荡双模式闸门（§25.4）

| 模式 | 触发条件 | 闸门 |
|---|---|---|
| 主动触发 | 单次提问后 | `enabled` + 会话 ≤3 次 + 问题 ≥10 字 + 必须有引用 |
| 深度触发 | 连续 ≥3 次追问同维度 | 单会话总次数 ≤5 |

### F4 图谱生长权重规则（§25.6）

| 项 | 值 |
|---|---|
| 首次共现建边 | `weight = 0.3` |
| 后续每次共现 | `+0.05`（cap 1.0） |
| 30 天未更新 | `×0.95` 衰减 |
| 双链格式 | `[[目标文档标题]]` 追加文末 |
| 首版是否改 search.go | **否** |

### F5 反馈画像机制（§25.7）

| 项 | 内容 |
|---|---|
| 评价入口 | 每个问答后 👍 / 👎 / ⏺ |
| 不评价即中性 | 中性信号记录但不触发微调 |
| 触发条件 | 累积 ≥3 条同类型评价 → 触发画像微调 |
| 保留期 | 90 天 + 定时清理 |

| 层 | 形态 | 职责 |
|---|---|---|
| `POLARIS_PATH` | SVG path 常量 | **几何唯一真源**，供 mask / 动画共用 |

## 十二、一句话总结

> **Oblivion 的功能设计可以概括为"一个内核 + 三种部署形态 + 五项核心认知能力 + 三层 UI 设计 + 一套发布工程学"。**
>
> - **内核**：Cordis DI + YAML Patch 声明式组合
> - **部署形态**：CLI / Desktop / （已移除的 Docker）
> - **核心认知**：问答闭环 + 思维激荡 + 图谱生长 + 反馈画像 + 内容创作
> - **UI 三层**：视觉语言（427 令牌）/ 界面结构（三栏 + 槽位）/ 组件（57 组件 + 188 图标）
> - **发布工程学**：三级版本 + 破坏性变更契约 + 迁移工具 + 镜像三级兜底

**累计**：**38 项功能**（§2.1）+ **41 条 ERRATA 教训** + **31 条 AC 验收**。
