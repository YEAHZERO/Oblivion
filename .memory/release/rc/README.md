# release/rc/ — 汇总级

alpha 增量累积够多、准备对外发布时，在这里写**一份用户能读的说明**。

与 alpha 的区别不是「更正式」，而是**读者不同**：

| | alpha 增量 | rc 汇总 |
| --- | --- | --- |
| 读者 | 自己 / 同伴 | 准备升级的用户 |
| 内容 | 改了哪些东西 | 从上一个正式版到现在，**用户会感知到什么** |
| 写法 | 可以按文件写 | 必须按影响写 |

**破坏性变更只在这里宣告**（RISK-111）—— 散在 alpha 增量里必然被漏看。

命名：`<版本>-rc.<序号>.md`，例 `v0.1.0-rc.1.md`。
