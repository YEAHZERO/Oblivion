## 二、API 对账结果：你的设计书 90% 正确，有 3 处必须改

我把设计书里的每个 API 都拿本机 `@deepseek-ai/dsh` 的真实产物核对了一遍：

| 设计书写法 | 真实实现 | 结论 |
|---|---|---|
| `inject: ['tools','llm','systemPrompt','session']` | `dsh-persona`：`inject = ["systemPrompt"]`；工具面 `inject: ['tools']` | ✅ 成立 |
| `ctx.tools.register(defineTool({...}))` | 完全一致，另需 `output.schema` + `render` | ✅ 成立 |
| `ctx.on('session/event', handler)` | 签名是 `ctx.on('session/event', (subject, event) => …)`，**首参是 session 实体** | ✅ 但形状要改 |
| `event.type === 'turn/end'` | `this.session.append("turn/end", { turn, reason })` | ✅ 成立 |
| `event.turnId` | ❌ **不存在**。turn 标识是 `event.data.turn` | ❌ **必须改** |
| `systemPrompt.section({ order: 60, content })` | 真实字段是 **`name` + `order` + `text`**，且要包在 `ctx.effect()` 里；`order` 走 `getSectionOrder('NAMED_CONST')` | ❌ **必须改** |
| `qa.source_type === 'qa_loop'` | 会话事件里没有这个字段；防回灌要用「注入标记 + 自己只读模型面工具」 | ❌ **必须改设计**（见下） |
| `config` 默认值 | 官方用 `z.object(...)` schema，不是裸 `interface` | ⚠️ 建议改 |
| `cordis.patch.yml` + `oblivion.bundle` | 工作区规范是 `dshx.yml`(id/entry/marker/kind) + `cordis.yml`(相对 overlay) | ⚠️ 按 WORKSPACE.md 改 |

**关于"防回灌"的重新设计**（这条最重要）：你的原意是"插件自己写进知识库的内容不要再被当成问答捞回来"。但 `session/event` 里没有 `source_type` 这个字段可用。可行的等价做法是：

1. 插件**只读**模型面（`turn/end` 事件 + session 事件日志），**自己绝不调用 LLM**，所以天然不会产生新 turn，不存在回灌；
2. `oblivion_capture` 工具加了 `origin: 'oblivion'` 标记且 `sources[].type === 'qa_loop'` 的条目，在 `exactDuplicate`/`passesRules` 里直接短路丢弃；
3. 会话内幂等用 `event.data.turn`（配合 session id）做 `Set`，这才是真实存在的键。

**关于语义去重与价值评估**：设计书写"LLM 判定 0.85 / LLM 打分 0.5"，但 `ctx.llm` 的公开面只有 `registerAdapter / registerConfigurableProviders / registerModelDiscovery`，`llm.stream(request)` 需要完整的 provider/model/messages 请求体（官方在 `agent-loop` 内部构造）。**插件侧安全、可验证的做法是先做确定性实现**（关键词重合度 + 规则打分），把 LLM 判定留成一个显式注入点，等 `ctx.llm` 的稳定公开调用面确认后再接。这属于**能力缺口**，按 plugin-only 规则我不去补 Host 接口。

```ts
import { homedir } from 'node:os'
import { isAbsolute, join, resolve } from 'node:path'

/** `~` and `~/x` are config conveniences; the Host may run from any cwd. */
export function expandHome(p: string): string {
  const home = homedir()
  if (p === '~') return home
  if (p.startsWith('~/') || p.startsWith('~\\')) return join(home, p.slice(2))
  return isAbsolute(p) ? p : resolve(p)
}
```

```ts
import { createHash } from 'node:crypto'

/** sha1 is enough here: this is a dedup key, not a security boundary. */
export function sha1(input: string): string {
  return createHash('sha1').update(input, 'utf8').digest('hex')
}

/** Collapse whitespace + strip punctuation so cosmetic edits still hash equal. */
export function normalizeForHash(text: string): string {
  return text
    .toLowerCase()
    .replace(/[\s\u3000]+/g, ' ')
    .replace(/[，。、；：！？,.;:!?"'“”‘’()（）\[\]【】《》<>`*_\-—]+/g, '')
    .trim()
}
```

### 3.6 `src/util/time.ts`

```ts
export const MS_PER_DAY = 86_400_000

export function now(): number {
  return Date.now()
}

export function ageDays(from: number, at: number = now()): number {
  // Clock guard: a backwards clock must never yield negative age.
  return Math.max(0, (at - from) / MS_PER_DAY)
}

export function isoStamp(at: number = now()): string {
  return new Date(at).toISOString()
}

/** `ts-<base36 ms>-<2 random chars>` — sortable by creation time. */
export function newId(at: number = now()): string {
  const rand = Math.random().toString(36).slice(2, 4).padEnd(2, '0')
  return `ts-${at.toString(36)}-${rand}`
}
```
