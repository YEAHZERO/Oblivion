## 二、做插件的实际流程（回答"我该如何制作插件"）

流程是这个，每一步都有校验，不是写完就完：

1. `dshx_status` — 看 Host / Guardian 状态
2. `dshx_claim_plugin` — 声明这个插件归当前会话，同时武装 Guardian
3. `dshx_scaffold(name, kind)` — 在工作区 `my-plugins/` 生成骨架（**不会覆盖已有项目**）
4. 写代码
5. `dshx_check` — 外部检查 + 客户端 Cordis 注入 + 构建产物交接（只证明 SOURCE_BUILT）
6. `dshx_activation_plan(name, change)` — 选定激活方式：`patch` / `manifest` / `preset` / `client` / `new-client` / `server` / `artifact`
7. 按方式激活（`dshx_hot_reload` 或 `dshx_activate_new_client`）
8. 实测行为——在验证之前，功能状态一直是 `RUNTIME_VERIFICATION_REQUIRED`
