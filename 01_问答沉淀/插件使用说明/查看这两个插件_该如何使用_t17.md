- 来源会话: `session-67cb0d9e-8043-42cb-81f7-d601e3aa1587`

## 问题

%LOCALAPPDATA%\ms-playwright\chromium-1243删

## 回答

删了，两个目录一起清掉（我上一条把这两个合起来说成"chromium-1243"，实际是两份）：

| 目录 | 大小 | 状态 |
|---|---|---|
| `%LOCALAPPDATA%\ms-playwright\chromium-1243` | 431.9 MB | 已删除 |
| `%LOCALAPPDATA%\ms-playwright\chromium_headless_shell-1243` | 270.1 MB | 已删除 |

删前核实：路径解析到 `C:\Users\liveu\AppData\Local\ms-playwright\...`（确认不是别的盘/别的路径）；从该目录启动的 `chrome.exe` **进程数 0**（之前那 5 个已杀，没有残留占用）。删后 C: 剩余 85.68 GB，目录里只剩 `.links` / `ffmpeg-1011` / `mcp-chrome` / `winldd-1007`。

顺带查了 `.links` 里引用这份缓存的另一个安装：`C:\Programs\AITech\CodexCLI\npm-cache\_npx\...\playwright-core` 是 **1.62.1，要 rev 1234 而不是 1243** —— 所以删 1243 不影响它；只有 desktop profile 里 dsh-browser 自带的 playwright 1.63.0 用 1243，而它现在配置成走 Edge 了。

两点备注：

- **万一需要恢复**（比如 Edge 通道出问题、想退回自带内核）：一条命令即可，约 310MB 下载 —— `node "C:\Users\liveu\.dsh\profiles\desktop\node_modules\playwright\cli.js" install chromium`；重启后也可以用 dsh-browser 的 `runtime.install` 动作装。
- 重启前**别指望平台搜索能出结果**：dsh-browser 还在用旧 config，现在既没有 msedge+authProfiles，也没有自带 chromium，跑 zhihu/weibo 搜索只会报错。回头重启 App 后说一声，我按前面那四条复核（status 的 credential、zhihu 搜索结果、进程里是不是 msedge.exe、空结果就调 headless）。
