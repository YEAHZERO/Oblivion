## 答案：`dsh-better-sidebar`

截图那个 **「任务管理」** 不是独立插件，是 **`dsh-better-sidebar` 0.24.1 内置的一个 tab**（官方 sidebar 不提供这个页）。证据：

- `C:\Users\liveu\.dsh\profiles\desktop\node_modules\dsh-better-sidebar\src\client\locales.ts:329` —— `subagent: '任务管理'`
- 同文件 `:337` —— `subagentCountRunning: '{count} 个子代理 · {running} 运行中'` ← 截图右上角那行"**4 个子代理 · 4 运行中**"就是它
- `README.md:53` —— 「**🧩 任务管理**（官方没有）：子代理拓扑实时预览 + 后台任务清单（退出码 / 实时输出 / 强制终止）」

## 它的能力（0.24.1）

- 主显示模式是**工作流图**：分层节点 + 贝塞尔连线，可拖拽平移、滚轮缩放到光标、包围盒居中适配，右下角控制条切换 **图 / 树**、折叠、缩放、适配；经典缩进树保留、键盘可导航（`README.md:226`）。
- 节点卡双段式：上段是类型徽章（主代理 / 子代理 / 成员 / 工作流 / 已完成聚合）+ 相位徽标 + 名称 + 元信息；下段是状态点 + 状态词 + 活动行（`README.md:227`）。
- 还能看**后台任务清单**（退出码 / 实时输出 / 强制终止）——就是本机 `job_*` 那类后台作业。
- 相关设置项：**检测到子代理时自动激活任务管理页**、**有新后台任务时自动激活**、**任务管理默认视图**（`src/client/locales.ts:271-274,404-405`）；窄屏不强制展开全屏抽屉（`:294`）。
