## ① profile 补丁：web-search-pro 接管 ctx.web（已写入，待重启生效）

[cordis.patch.yml](C:/Users/liveu/.dsh/profiles/desktop/cordis.patch.yml#L74-L96) 由 72 行变 **96 行**，尾部两条即所需配置：

```yaml
- id: web-search-pro
  name: "dsh-web-search-pro"
  config:
    registerProvider: true
- id: web
  name: "@deepseek-ai/dsh-web"
  config:
    searchProvider: web-search-pro
    fetchProvider: web-search-pro
```

上面 L74-87 是中文注释块，记明背景与一条坑：**patch 是整段替换 config 而非合并**，所以 search/fetch 必须一起写——只写一个，另一端会回落到宿主自带 provider（`dsh-base/cordis.patch.yml:478` 的 deepseek-official / `:483` 的 http），两个可用 provider 并存时 `web_search`/`web_fetch` 会报 `WEB_PROVIDER_AMBIGUOUS`。

- 校验：用 `js-yaml` 解析 → `YAML OK - 9 top-level entries`，尾部两条 JSON 与预期逐字一致（防止 YAML 写坏导致 DSH 起不来）。
