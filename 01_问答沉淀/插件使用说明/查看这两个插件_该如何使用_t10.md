## ① 搜索/抓取已分工写入 profile 补丁

文件：[cordis.patch.yml](C:/Users/liveu/.dsh/profiles/desktop/cordis.patch.yml)（尾部新增/改写，现 128 行）

```yaml
- id: web-search-free
  name: "dsh-free-search"
  config: { provider: bing, bingMarket: zh-CN, disabledEngines: [], fallbackOrder: [exa, tavily, firecrawl] }
- id: web
  name: "@deepseek-ai/dsh-web"
  config: { searchProvider: ddg, fetchProvider: web-search-pro }
```

- **搜索 → free-search**：写它自己的 provider id `ddg`（`dsh-free-search/lib/index.js:3160`）。这是刻意的——`lib/index.js:3578` 只在字段未设或仍是 `deepseek-official` 时自动接管，`:3586` 在字段指向别人时只 warn，写自己的 id 让两个分支都不触发，等于把归属钉死。
- **默认 bing + 优先三家带 key**：`provider: bing`、`fallbackOrder: [exa, tavily, firecrawl]`。语义是**提到最前**而不是限定集合（`normalizeFallbackOrder` 会把配置项 + `DEFAULT_FALLBACK_ORDER` + `ALL_ENGINES` 拼接去重，`:171-176`），所以这三家没额度时仍会继续走 keenable/parallel/… 而不是断掉。
- **抓取 → web-search-pro**：`fetchProvider: web-search-pro`（`lib/index.js:106-112` 双注册），拿到裁剪正文与 `offset=N` 续读提示。
- **校验**：js-yaml 解析通过 —— `YAML OK - 10 entries`，ids = ui-settings-account, ui-chat, ui-settings, insert(2), agent-default-model, permission, llm-pi-ai, web-search-free, web-search-pro, web。
- **已生效，无需重启**（profile 补丁层被 Host 监视）：会话提示词里引擎表已变成 `Enabled engines: exa, tavily, firecrawl, keenable, …`、`fallback uses: exa -> tavily -> firecrawl -> keenable -> …`、`Current mode: bing`；`web_call sources.status` 末段：

## ④ 怎么装 @anweat/dsh-browser

```powershell
& "$env:APPDATA\npm\dsh.cmd" plugin --profile desktop add @anweat/dsh-browser@0.2.1
```

版本对得上：npm 最新 `0.2.1`，本机 `dsh.cmd --version` = `0.2.0-rc.2`，而 peer 范围是 `>=0.2.0-rc.2 <0.2.1-0`。装完要**重启 App**；Playwright/Chromium 内核不随包下载，用插件自己的 `runtime.status` 看状态、`runtime.install` 补装，缓存想挪到别的盘就在同一组配置里给 `executablePath`。装完之后 `sources.status` 里那 11 个浏览器类平台（xiaohongshu / twitter / reddit / zhihu / weibo / douyin …）才会从 "requires the optional dsh-browser plugin" 变成 ready。
