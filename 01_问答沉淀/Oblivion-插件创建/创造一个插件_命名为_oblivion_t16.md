## 一、按你这句落地的两件事

| 要求 | 实现 |
| --- | --- |
| **知识库位置可自定义** | `config.mdRoot` 接受任何绝对路径或 `~/` 写法。示例（也写进了 README §9.4）：<br>`config: { mdRoot: 'D:/Knowledge/OblivionKB' }` |
| **一经定义就自动创建 `01_问答沉淀\` 等** | 新增 `ensureMdDirs()`，**在插件装载时**就把知识库根 + 全部分类目录建好 —— **不再等第一次落盘**：`00_导入文件` `01_问答沉淀` `02_Wiki页面` `03_创作产物` `99_其他` |

端到端实证（我刚跑的真机脚本，用的是**自定义**位置而非默认）：

```
apply(ctx, { mdRoot: '…/我的知识库' })
→ [oblivion-core] loaded
→ 自动创建的目录: 00_导入文件 | 01_问答沉淀 | 02_Wiki页面 | 03_创作产物 | 99_其他
→ 装载日志: [oblivion-core] 知识库目录就位：…\我的知识库（5 个分类）
```

**性质**：幂等（`recursive: true`）、**非阻塞**（失败只 warn，不影响装载与问答链路）、**只创建不删除**。

顺手加了一道安全边界：`mdClassify` 的目录名会**消毒**（去掉 `..` 片段、盘符、非法字符），所以配置里的目录名**不可能逃出 `mdRoot`**（`safeDirName('../../etc')` → `etc`）。
