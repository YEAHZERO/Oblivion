## 先更正：机制其实一直是好的

上一条我说「等待循环根本没等，同一秒就判定进程消失」—— **这是错的**。原因是我生成批处理时把时间戳**算了一次就写死**，三行日志显示同一秒，是**冻结的时间戳**，不是真实时间。

而且日志证明它工作正常：当前主进程 **PID 2024 的父进程正是 `24316`**，就是日志里 `relauncher armed via WMI: pid=24316` 那个 WMI 创建的 cmd —— **应用是它拉起来的，不是你手动开的**。

## ① 不弹控制台窗口

`Win32_ProcessStartup.ShowWindow = 0` 可以隐藏，但**不能走 `Invoke-CimMethod`** —— 它无法为嵌入式实例推断 CimType（`无法从提供的 .NET 对象推断 CimType`）。必须用 WMI v1 形式：

```powershell
$startup = ([wmiclass]'Win32_ProcessStartup').CreateInstance()
$startup.ShowWindow = 0
([wmiclass]'Win32_Process').Create($cmdLine, $cwd, $startup)
```

顺带试并否掉了那条常见的「无窗口」路子 —— **`wscript` + VBS 在这里行不通**：`wscript.exe` 是 GUI 子系统程序，经 WMI 创建时根本不启动（VBS 直接跑正常、经 WMI 无任何输出）。
