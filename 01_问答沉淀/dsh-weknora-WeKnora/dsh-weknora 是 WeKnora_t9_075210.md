## 实现情况

### ① 品牌图片可换（多格式）✅

`设置 → Oblivion 品牌 → 品牌图形`：

- 文件选择器 `accept="image/*"` —— PNG / JPEG / WebP / GIF / SVG / AVIF / BMP / ICO 都能读
- **>256px 的位图自动 canvas 缩放**到 256px；SVG **保持矢量不缩放**
- 缩放后仍超 512KB 就自动转 JPEG(0.85)；超过上限则明确报错而不是静默失败
- 「恢复北极星」一键回到内置图形

### ② 关闭接管 → DSH 恢复原生外观 ✅

「接管 DSH 品牌」开关。关掉时**不是**隐藏、也不是改样式，而是**真正 dispose 掉本插件在品牌槽位的注册** —— `single` 槽的 `lowest renders` 规则下，官方那条(priority 0)立刻重新成为渲染者，鲸鱼图标与 wordmark 立即回来。

有个细节我特意处理了：**设置分节本身永远注册**，不受这个开关影响 —— 否则你关掉接管后就再也找不到地方打开了。

### ③ 侧栏面板可多选 ⚠️（有个真实边界，必须讲清）

做成了**通用机制**：自动发现所有「可嵌入的面板提供方」，勾选任意多个，每个成为左侧栏一个独立条目（从 `order:5` 起递增，「插件」下方）。

发现方式：cordis 的 `ctx.reflect.provide()` 把服务登记在 `ctx.reflect.store`，枚举它、筛出带 `render()` 的服务；反射不可用时退回已知名单探测（`market`）。

**但「任意设置页」做不到，原因是硬的**：设置页正文由设置弹窗用**它自己那个窄化过的 `renderSlot`** 渲染，而 `main` 声明为 `{kind:"keyed", scope:"root"}` 且**没有 children** —— 从 `main` 或 `sidebar.panellist` 里没有任何公开途径去渲染别的设置分节正文。所以能搬进侧栏的只能是**主动暴露渲染接口**的插件，目前只有 `dshmarket`（`ctx.provide('market', { render })`）。装了更多这类插件，候选列表会**自动变长**，不用改本插件。

## 顺手修掉的一个缺陷

发现逻辑里 `ctx.get(name)` 原本没有单点保护 —— 某个服务尚未就绪时它会抛错，而它在 try 块内，**一次失败就会中断整轮枚举、把后面的提供方全漏掉**。已改为逐个服务单独 try/catch。这个如果不修，发现功能的可靠性会随服务数量增加而下降。
