## 为什么我上一轮"看不到"，opencode"看得到"——路径对比

| 路径 | 结果 | 原因 |
| --- | --- | --- |
| 本机直抓：`web_fetch` / `read.fetch` / `read.contents`（Exa /contents） | 403 / 超时 / **空返回** | Baidu 安全验证按 IP 拦你的出口；Exa 实时抓取也拿不到 |
| bing / so360 短摘要 | 1 行 snippet | 免费引擎索引摘录短 |
| Parallel（key，opencode 用它） | pt吧 相关帖子 snippet | 服务商索引摘录 |
| **Exa（key）+ includeDomains=tieba.baidu.com** | **pt吧 帖子多回复摘录** ✅ | 索引里存了更长的正文快照 |

关键区别：403 只锁死"**实时抓页面**"这一条路；**"查已索引内容"（exa/parallel 搜索）这条路是通的**，opencode 和我（exa 那条查询）走的是同一条路。
