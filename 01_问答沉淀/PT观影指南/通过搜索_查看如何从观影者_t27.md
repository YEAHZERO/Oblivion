**行为序列**（面板按钮）：
1. 点「重启 DSH」→「确认重启」（有确认步骤，防误点）；
2. POST `/obl-brand/restart`（原路由：预清扫 + 派生 helper，返回 202）；
3. **收到 202 立即铺黑遮罩 + `window.close()` → 窗口隐藏（秒关）**；
4. 后台：helper 做清扫/溯源/ARM relauncher/杀最外层主进程；
5. relauncher 轮询到进程消失 → 重新 `start`，新窗口出现（数秒后）。

**崩溃弹窗根因**：新快速脚本同时 `Stop-Process` 了 host 与 main，host 先退 → Electron 主进程判定 "host exited with 4294967295" 弹致命恢复框。回退后的原脚本只杀最外层 Electron 主进程，主进程一死 host 随 job object 一起消失，不会出现该弹窗。

## 盲区

- "安全重启"仍是硬杀主进程（原设计如此，非 `app.quit` 优雅链）；插件层无法触达 `app.quit`，要真实优雅需要上游给 IPC。
- `window.close()` 依赖托盘确认标记（已存在）；若窗口因更新弹窗等被拦，遮罩兜底显示"正在重启"。
- 新客户端 bundle 需**重启 DSH 一次**才加载（本次验收前必须做一次）。
