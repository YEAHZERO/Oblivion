## 问题

但是托盘右键「退出」时dsh面板立马就关闭了，而快速重启则是要等好几秒才会关闭面板。我需要的是点击按钮后dsh页面直接关闭，还可以加上优雅：app.quit() → before-quit → 有活动任务先弹确认 → finishQuit() → backend.close()（Host 按序 dispose 全部插件、刷会话）的关闭。主要是UI显示的问题

## 回答

`window.close()` 在 DSH 里就是"隐藏到托盘"（主窗口 close 事件会 preventDefault → hide），这正好是你要的"页面立刻消失"。先确认首次关闭的托盘确认标记是否已存在（存在=立即隐藏、不弹框）：

实现"点击即关页面"：成功受理后先铺全屏"正在重启"遮罩，再 `window.close()` 把主窗口藏到托盘（有 `background-close-confirmed` 标记，立即隐藏不弹框）。

## 结论

已把「点完即关」做进面板按钮（客户端侧）：现在点击后约 **0.2–0.5 秒**内全屏遮罩盖住并立即触发 `window.close()`——这就是托盘「退出」用的同一条隐藏路径（`background-close-confirmed` 标记 2026-10-04 已存在，**立即隐藏、不弹托盘确认框**）。之后 helper 在后台完成强杀 + 重新拉起。优雅链（`app.quit → before-quit → finishQuit → backend.close`）**插件侧无法触发**（Electron 主进程只接受 host 的 ready/platform-session/shutdown-complete/fatal 四类消息，没有 quit 通道），要优雅关闭只能用托盘「退出」——它同样是"窗口先消失、后台再 dispose"。

## 要点

| 环节 | 改后行为 |
| --- | --- |
| 点击按钮 | 先弹确认（"确认重启"）——保留原有二次确认，防误点 |
| 确认后 | POST `/obl-brand/restart`（快速路由，仅派生 helper，秒回 202） |
| 202 到达 | 立即铺全屏遮罩「正在重启 DSH…」→ 两帧后 `window.close()` → 主窗口**隐藏到托盘**（这就是"页面直接关闭"） |
| 关闭失败兜底 | 关窗被拦（如更新弹窗开着）时黑色遮罩保持，进程仍会被 helper 终止 |
| 后台 | helper：ARM relauncher → 400ms → 按 exe 路径强杀全部进程 → relauncher 100ms 轮询到进程消失 → 重新 `start` 应用 |
| 新窗口 | 重新启动后自动出现新主窗口 |

**关于"优雅"的边界**：托盘「退出」= `app.quit()` 链（有活动任务先弹确认 → `finishQuit` 隐藏窗口 → `backend.close()` 顺序 dispose 插件/刷会话）——它的 UI 也是秒关，因为 `finishQuit` 一开始就 `mainWindow.hide()`。面板按钮做不到这一段，只能"秒关 UI + 硬杀"；硬杀会丢最后一点未落盘增量（与 bat 相同）。

## 盲区

- `window.close()` 依赖 DSH 主窗口"关闭即隐藏到托盘"的行为；若将来 DSH 改成"关闭即退出"，这里就会变成直接退出（仍是预期效果）。
- 遮罩目前是纯色 `#111` + 一行字，若要改成纯黑/加品牌图标可再调。
- 托盘退出在**有活动任务时**会先弹确认框，不确认不关——那时它反而比快速重启慢。
