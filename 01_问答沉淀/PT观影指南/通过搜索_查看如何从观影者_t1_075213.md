1. **选站**：入门挑"无考核/每日送上传"的宽松站（如大青虫）；追求冷门电影再挑影视发布强的站，两站组合最稳。
2. **过考核（如有）**：顺序是刷上传 → 做种率 → 魔力值 → 下载量。下 **Free/2xFree、做种人少、体积小**的种子，上传效率最高；用 [IYUUAutoReseed](https://github.com/ledccn/IYUUAutoReseed) 辅种拉做种率；过考核后别删白嫖种子（继续赚魔力值）。
3. **日常观影流**：
   - 看**资源标识**再下：Free/2x 省下载量、H&R 必须挂满做种小时（欠了记 HR，多了封号）；
   - **版本选择**：纯观影 1080p Blu-ray/WEB-DL 性价比最高，4K 留给好屏幕，优先官释/内封（字幕、花絮完整）；冷门片走求资源区；
   - **感谢/推荐**：看完发感谢帖 = 社交信用，是拿邀请码、买魔力值、混站圈的正道；
   - **辅种**：同一部热门老片多站挂种，做种率和魔力值双收；
   - 播放端：NAS + Plex/Jellyfin + [PT-Plugin-Plus](https://github.com/ronggang/PT-Plugin-Plus)（多站搜片+元数据）。
4. **生存底线**：分享率别低于站点下限（多为 0.5–1.0）；长尾小体积热门电影是"挂机赚上传"的最佳资产；**passkey 永不过泄**（截图打码）、换 IP 要报备、不随便发邀请（连坐制度）。
5. **工具**：qBittorrent / UT 2.0.4 / Transmission（群晖）+ PT-Plugin-Plus 搜索。
